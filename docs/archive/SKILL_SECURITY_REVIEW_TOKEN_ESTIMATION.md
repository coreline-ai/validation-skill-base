## 2. 검사 항목별 상세 분석

### 2.1 정적 분석 (Static Analysis)

```
검사 항목:
- SKILL.md 파싱
- REFERENCE.md 분석
- scripts/*.py, *.sh 검사
- YAML/JSON 설정 파일 확인
```

| 항목 | 소요 토큰 | 설명 |
|------|----------|------|
| 파일 파싱 | 500-1,500 | 각 파일 내용 읽기 및 구조 분석 |
| 패턴 매칭 | 1,000-2,000 | 보안 패턴 정규식 검사 |
| **소계** | **1,500-3,500** | |

### 2.2 보안 패턴 검사 (Security Pattern Check)

```
검사 패턴:
1. API 키/시크릿 노출
   - sk-*, api_key.*, secret.*, token.*, password.*
   - AWS_ACCESS_KEY, PRIVATE_KEY, etc.

2. 위험한 명령어 패턴
   - rm -rf, eval(), exec(), system()
   - curl | bash, wget | sh

3. 개인정보 패턴
   - 이메일, 전화번호, 신용카드, 주민번호
   - IPv4, IPv6

4. 외부 URL 검사
   - http://, https:// URL 추출
   - 알려진 악성 도메인 확인

5. 데이터 전송 패턴
   - fetch(), XMLHttpRequest, axios
   - 외부 서버로 데이터 전송 코드
```

| 패턴 | 소요 토큰 |
|------|----------|
| API 키 검사 | 300-500 |
| 위험 명령어 | 400-700 |
| 개인정보 검사 | 300-500 |
| URL 검사 | 500-800 |
| 데이터 전송 | 500-800 |
| **소계** | **2,000-3,300** |

### 2.3 OWASP LLM Top 10 체크

```
LLM01: Prompt Injection
- 사용자 입력이 프롬프트에 직접 삽입되는지 확인
- 시스템 프롬프트 노출 가능성

LLM02: Insecure Output Handling
- LLM 출력이 검증 없이 실행되는지 확인
- 코드 실행 패턴 (eval, exec)

LLM06: Sensitive Information Disclosure
- 훈련 데이터 포함 여부
- 민감 정보가 노출될 가능성

LLM08: Excessive Agency
- 파일 시스템 접근 권한 과다 여부
- 네트워크 요청 권한 확인
```

| 항목 | 소요 토큰 |
|------|----------|
| LLM01 검사 | 400-600 |
| LLM02 검사 | 300-500 |
| LLM06 검사 | 300-500 |
| LLM08 검사 | 400-600 |
| **소계** | **1,400-2,200** |

### 2.4 Garak 프로브 실행 (선택적)

```
Garak 프로브 카테고리:
- promptinject: 프롬프트 인젝션 취약점

- packagehallucination: 가짜 패키지 의존성
```

| xss | 400-700 | 2-3 | 800-2,100 |

## 4. 비용 최적화 전략

### 4.1 토큰 절감 방법

| 방법 | 절감 효과 | 설명 |
|------|----------|------|
| **캐싱 활용** | 30-50% | 이전 검사 결과 재사용 |
| **증분 분석** | 40-60% | 변경된 부분만 재검사 |
| **프로브 선택적 실행** | 50-70% | 위험도에 따라 Garak 프로브 선택 |
| **요약 보고서** | 20-30% | 상세 보고서 대신 요약본 제공 |

### 4.2 티어별 검사 옵션

```
🟢 QUICK (빠른 검사)
- 정적 분석만
- 핵심 보안 패턴만
- 기본 OWASP 체크
소요: 5,000-8,000 토큰

🟡 STANDARD (표준 검사) - 권장
- 정적 분석 전체
- 전체 보안 패턴
- OWASP LLM Top 10 전체
- 선택적 Garak 프로브
소요: 12,000-20,000 토큰

🔴 THOROUGH (심층 검사)
- 정적 분석 전체
- 전체 보안 패턴
- OWASP LLM Top 10 전체
- 전체 Garak 프로브
- 상세 보고서
소요: 25,000-40,000 토큰
```

## 7. 권장 설정

### 개발용

```yaml
tier: STANDARD
use_garak: selective
cache_enabled: true
예상 토큰/스킬: 10,000-15,000
```

### CI/CD용

```yaml
tier: QUICK
use_garak: false
cache_enabled: true
incremental: true
예상 토큰/PR: 5,000-8,000
```

### 릴리스용

```yaml
tier: THOROUGH
use_garak: all
cache_enabled: false
예상 토큰/스킬: 25,000-40,000
```
