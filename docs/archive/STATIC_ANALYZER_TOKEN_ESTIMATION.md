# 독립형 정적 분석기 토큰 소요 분석

## 개요

스킬 파일(.md, .json, .yaml, .py, .sh)에 대한 정적 분석만 수행하는 독립형 도구입니다. LLM을 통한 동적 프로빙 없이, 패턴 매칭과 규칙 기반 검사만 수행합니다.

---

## 1. 토큰 소요 구조

### 전체 프로세스 토큰 소요

```
┌─────────────────────────────────────────────────────────────┐
│  INPUT TOKENS                              OUTPUT TOKENS    │
├─────────────────────────────────────────────────────────────┤
│  1. 파일 로드           500-2,000                           │
│  2. 정적 분석 실행       1,000-3,000   →  500-1,000         │
│  3. 패턴 검사           500-1,500    →  300-800            │
│  4. 보고서 생성         500-1,000    →  800-1,500          │
├─────────────────────────────────────────────────────────────┤
│  MINIMUM:   2,500-7,500      →      1,600-3,300           │
│  MAXIMUM:   3,500-6,500      →      2,600-4,300           │
│  TOTAL:     4,100-10,800 토큰                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. 단계별 상세 분석

### 2.1 파일 로드 단계

```python
# 분석 대상 파일 유형
files = [
    "SKILL.md",           # 항상 존재
    "REFERENCE.md",       # 선택적
    "EXAMPLES.md",        # 선택적
    "*.json",             # 설정 파일
    "*.yaml",             # 설정 파일
    "scripts/*.py",       # Python 스크립트
    "scripts/*.sh",       # Shell 스크립트
]
```

| 파일 유형 | 평균 크기 | 토큰 수 |
|----------|----------|--------|
| SKILL.md만 | 1,000-2,000字符 | 500-800 |
| + REFERENCE.md | +2,000-4,000字符 | +800-1,500 |
| + scripts | +500-2,000字符 | +200-700 |
| **최대** | | **2,500-3,000** |

### 2.2 정적 분석 실행 단계

```
검사 항목:
┌─────────────────────────────────────────────────────────┐
│ 1. 구조 분석                                            │
│    - YAML frontmatter 확인                              │
│    - name, description 필드 검증                         │
│    - 필수 섹션 존재 확인                                 │
│                                                         │
│ 2. 코드 블록 추출                                       │
│    - ```python, ```bash, ```javascript 등              │
│    - 인라인 코드 패턴 (`code`)                           │
│                                                         │
│ 3. 외부 참조 식별                                        │
│    - URL 링크                                            │
│    - 파일 경로 참조                                      │
│    - import/require 문                                  │
└─────────────────────────────────────────────────────────┘
```

| 작업 | 토큰 소요 |
|------|----------|
| 구조 분석 | 200-400 |
| 코드 블록 추출 | 300-600 |
| 외부 참조 식별 | 200-400 |
| **소계** | **700-1,400** |

## 3. 스킬 크기별 총 토큰 소요

### 소형 스킬 (SKILL.md만)

```
파일: SKILL.md (50-100줄, ~1,500字符)
코드 블록: 0-2개
```

| 단계 | 입력 | 출력 | 합계 |
|------|------|------|------|
| 파일 로드 | 500 | - | 500 |
| 정적 분석 | 500 | 200 | 700 |
| 패턴 검사 | 300 | 150 | 450 |
| 보고서 | 300 | 500 | 800 |
| **합계** | **1,600** | **850** | **2,450** |

### 중형 스킬 (SKILL.md + REFERENCE.md)

```
파일: SKILL.md + REFERENCE.md (200-300줄, ~4,000字符)
코드 블록: 3-8개
```

| 단계 | 입력 | 출력 | 합계 |
|------|------|------|------|
| 파일 로드 | 1,500 | - | 1,500 |
| 정적 분석 | 800 | 300 | 1,100 |
| 패턴 검사 | 500 | 200 | 700 |
| 보고서 | 500 | 700 | 1,200 |
| **합계** | **3,300** | **1,200** | **4,500** |

### 대형 스킬 (복수 파일 + 스크립트)

```
파일: SKILL.md + REFERENCE.md + scripts/
코드 블록: 10+개
스크립트: 2-5개
```

| 단계 | 입력 | 출력 | 합계 |
|------|------|------|------|
| 파일 로드 | 2,500 | - | 2,500 |
| 정적 분석 | 1,200 | 500 | 1,700 |
| 패턴 검사 | 800 | 350 | 1,150 |

| **합계** | **5,200** | **1,850** | **7,050** |

## 8. 구현 아키텍처 추천

```
┌─────────────────────────────────────────────────────────┐
│                    CLI / API Entry                      │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │ File Loader │→│ Static Analyzer │→│ Reporter    │    │
│  └─────────────┘  └─────────────┘  └─────────────┘    │
│                          │                               │
│                  ┌───────┴───────┐                       │
│                  │  Pattern DB   │                       │
│                  │  - 53+ patterns                       │
│                  │  - Regex rules                        │
│                  │  - Severity mapping                   │
│                  └───────────────┘                       │
└─────────────────────────────────────────────────────────┘
```

**핵심 컴포넌트:**

1. **FileLoader** - 스킬 파일 로드 및 파싱
2. **StaticAnalyzer** - 정적 분석 및 패턴 매칭
3. **PatternDB** - 보안 패턴 데이터베이스
4. **Reporter** - 보고서 생성 (JSON, Markdown, HTML)

**LLM 사용 최소화:**
- 파일 파싱: 불필요 (순수 Python)
- 패턴 매칭: 불필요 (정규식)
- 보고서 생성: 최소화 (템플릿 기반)
- 요약 생성: 선택적 (LLM 활용)
